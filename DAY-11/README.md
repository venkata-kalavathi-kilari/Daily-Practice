## Sum of First N Natural Numbers

## Problem 
Given a number **N**, find the sum of the first **N natural numbers**.

### Example

Input:
5


Output:
15

Explanation:
1 + 2 + 3 + 4 + 5 = 15

## Approach

1. Read the value of `N`.
2. Initialize a variable `sum` with `0`.
3. Use a loop from `1` to `N`.
4. Add each number to `sum`.
5. Print the final value of `sum`.

## Time Complexity

O(N)


## Space Complexity

O(1)
