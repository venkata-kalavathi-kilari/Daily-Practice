# Count Positive Numbers

## Problem
Given `n` numbers, count how many numbers are positive.

A positive number is a number greater than `0`.

## Algorithm
1. Read the value of `n`.
2. Initialize `count = 0`.
3. Read each number one by one.
4. If the number is greater than `0`, increment `count`.
5. Print the final count.

## Example

### Input
```text
5
10 -2 5 0 -7
```

### Output
```text
2
```

So the count is `2`.

## Time Complexity
- **O(n)**

## Space Complexity
- **O(1)**
