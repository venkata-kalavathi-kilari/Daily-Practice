# Sum of Natural Numbers
## Problem
Given a number `n`, find the sum of the first `n` natural numbers.

### Example

**Input:**
5


**Output:**
15


**Explanation:**
1 + 2 + 3 + 4 + 5 = 15

## Algorithm

1. Read the input number `n`.
2. Use the formula:

   Sum = n × (n + 1) / 2

3. Store the result in a variable.
4. Print the result.

## Time Complexity
O(1)


## Space Complexity
O(1)
