# Remove Spaces from a String

## Problem
Given a string `s`, remove all spaces from the string and return the modified string.
## Algorithm
1. Take the input string `s`.
2. Use `s.replace(" ", "")` to replace all spaces with an empty string.
3. Return the modified string.

## Example 1

### Input
s = "geeks for geeks"


### Output
"geeksforgeeks"


### Explanation
All spaces are removed from the string.

## Time Complexity
- **O(n)**

## Space Complexity
- **O(n)**
