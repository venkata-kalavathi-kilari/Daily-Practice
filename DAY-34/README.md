# Check if Two Strings are Equal

## Problem
Given two strings `s1` and `s2`, determine whether both strings are exactly the same. Return `true` if they are equal; otherwise, return `false`.

## Algorithm
1. Take two input strings `s1` and `s2`.
2. Use the `equals()` method to compare their contents.
3. If both strings are identical, return `true`.
4. Otherwise, return `false`.

## Example 1

### Input
```text
s1 = "hello"
s2 = "hello"
```

### Output
```text
true
```

### Explanation
Both strings have the same characters in the same order, so they are equal.
m

## Time Complexity
- O(n), where `n` is the length of the strings.

## Space Complexity
- O(1)
